# GuardAgent OS

GuardAgent OS is an AI-powered Binance trading command center built with Python and Streamlit for the Binance Agent OS Mini Hackathon — Track A. The project connects with a Binance Sub-account API and brings real-time market data, account balance monitoring, price updates, order-book analysis, market signals, AI risk checks, WebSocket updates and safety guardrails into one dashboard. The goal is to give an AI agent better market context before making a decision. Built for development, experimentation and demonstration. API credentials are kept locally and must never be uploaded to GitHub. Never share real API keys, API secrets or private account information.

## Features
- Binance Sub-account API integration
- Real-time market data
- Live account balance
- Price monitoring
- Order-book analysis
- AI risk analysis
- Market signals
- Safety guardrails
- WebSocket real-time updates
- Trading-focused dashboard

## Technology
Python • Streamlit • Binance API • WebSocket • Pandas • Requests • python-dotenv

## Installation
Clone the repository, install the required packages with `pip install -r requirements.txt`, configure your Binance API credentials locally in a `.env` file, and start the application with `streamlit run app.py`. The application runs locally using the Streamlit address shown in the terminal.
